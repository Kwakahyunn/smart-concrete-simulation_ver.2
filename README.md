## 실제 실험에서 권장하는 공통 조건
- 모르타르/콘크리트 시험체: 190 × 90 × 57 mm
- 관: 중앙 매립, 길이 약 200 mm
- PTFE 내경 9.5mm, 외경 12.7mm / PVC 내경 10mm, 외경 12mm
- 위·아래 각 3개, 전체 6개의 토출구 (구멍의 실제 직경과 중심 간격은 아직 측정되지 않아 시각화에는 3쌍 균일 간격을 임시 적용)
- 보수재: 식용색소 + 글리세린 수용액 + 에폭시 혼합
- 30 mL, 60초 연속 주사기 주입 권장. 실제로 가능한지 소규모 예비시험 후 확정하세요.
- 주입 종료 후 30초 배출 관찰을 가정

## 예측 결과 해석 주의
이 수치는 실험 결과가 아니며 점도, 주입 압력, 구멍 직경, 균열 부피, 재료 특성 등 실측 물성이 없는 상태의 민감도 예시입니다.
관 내부 기하학적 용적은 계산 가능하지만 유량/잔류/균열 분배는 PTFE(균열 66%, 잔류 5%), PVC(균열 58%, 잔류 12%)라는 가정에 기반합니다.
시간 계산 또한 대체 유동모델(surrogate)로, 실험 이동 시간을 검증하지 않습니다.
유량보존: 주입량 = 균열 유입 예측량 + 관 출구 배출 예측량 + 관 내 잔류 예측량.
실측할 수 없는 균열 유입량은 주입량-출구배출-관잔류 등으로 추정 가능하지만, 손실·누출과 체적 오차를 확인해야 합니다.

## 실제 실험 측정 권장
- 두 관 각각 동일한 30 mL 동일 혼합물 사용, 주입 시간 타이머로 기록
- 첫 측면 토출 시각 / 관 출구 도달 시각을 각각 영상으로 기록
- 출구 배출액을 별도 컵에 수거 후 부피 또는 무게 측정
- 관 잔류량은 주입 전후 무게, 세척 후 회수량 등 별도 측정 절차로 보정
- 가능하면 각 구멍별 실제 토출량도 기록하고 3회 이상 반복하여 편차 표시
- 주사기의 크기 및 보수재 점도/배합비에 따라 30mL 단회 주입의 실행 가능성을 먼저 확인

기존 시스템 시연 모드의 습도·센서·세척 단계는 미래 시스템 컨셉 표현이지 실제 모사 실험 데이터가 아닙니다.
